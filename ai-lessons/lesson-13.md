# Lesson 13: Capstone Portfolio Brainstorming

**Duration:** 1.5 Hours
**Objective:** Design a complex, multi-loop project that the student can build independently to showcase their skills for college applications.
**Recommended Reading:** [How to Write a Product Requirements Document (PRD)](https://www.atlassian.com/agile/product-management/requirements)

## 1. Concept: What Makes a Strong Portfolio Project? (30 mins)
* Colleges look for projects that solve real problems, demonstrate complex architecture, and are actually deployed.
* Introduction to the Product Requirements Document (PRD): How professional engineers map out a project before writing a single line of code.

## 2. Activity: The Brainstorming Session (30 mins)
* Use the "Crazy 8s" method: Generate 8 wild project ideas in 8 minutes. 
* Discuss ideas that combine their current skills: Go backend, LLM integration, and interactive loops. 
* *Potential Ideas to suggest:* An AI-powered Discord bot that manages study schedules, a text-based multi-loop simulation game with dynamic AI events, or a local server dashboard.

## 3. Activity: Drafting the PRD (30 mins)
* Pick the best idea and start outlining the PRD.
* **Define the MVP (Minimum Viable Product):** What is the absolute smallest version of this that works?
* **Identify the Stack:** Go for the backend, OpenAI/Claude for the AI, and where it will live (e.g., GitHub, a local Docker container, or a cloud server).
* Leave the lesson with a concrete roadmap of what to build next.

## 4. Development Roadmap
* Week 1: Core backend logic and loop
* Week 2: AI integration and tool calling / MCP
* Week 3: Persistence and error handling
* Week 4: Polish, documentation, and deployment
